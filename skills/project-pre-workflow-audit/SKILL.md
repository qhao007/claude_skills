# 工作流执行日志准备

此技能在工作流执行开始时创建执行日志，用于在多个子代理/步骤之间同步信息。

## 输入参数

用户应提供：
- **工作流名称**：用于生成日志文件名（如 `pcie_debug_flow` → `pcie_debug_flow_log.md`）

## 执行步骤

### 1. 定位 .dvv 目录

直接在当前工作目录下查找或创建 `.dvv` 文件夹：
1. 如果当前目录存在 `.dvv` 文件夹，使用它
2. 如果不存在，在当前目录创建 `.dvv` 文件夹

```bash
# 直接在当前目录创建 .dvv
mkdir -p .dvv
```

### 2. 检查并归档旧日志

1. 在 .dvv 目录下查找是否已存在 `{workflow_name}_log.md`
2. 如果存在：
   - 在 .dvv 下创建 archived/ 子目录（如果不存在）
   - 将旧文件移动到 archived/，命名格式：`{workflow_name}_log_{timestamp}.md`
   - timestamp 格式：`YYYYMMDD_HHMMSS`

### 3. 创建新日志模板

创建 `{workflow_name}_log.md`，包含以下结构：

```markdown
# 工作流执行日志: {workflow_name}

> **创建时间**: YYYY-MM-DD HH:MM:SS
> **执行代理**: {agent_name/ID}
> **状态**: 进行中

---

## 执行目标

[描述此工作流的执行目标]

---

## 执行记录

### Step 1: [步骤名称]
- **时间**: YYYY-MM-DD HH:MM:SS
- **执行者**: [代理名称]
- **目标**: [此步骤的目标]
- **做了什么**: [具体操作]
- **结果**: [执行结果]
- **输出文件**: [生成的文件的相对路径]
- **遗留问题**: [如有]
- **注意事项**: [如需提醒后续代理注意的问题]

---

## 当前状态

- 进度: X/Y 步骤
- 上一步: [上一步骤名称]
- 下一步: [待执行步骤]

---

## 信息同步区

[用于在步骤之间传递上下文信息]
```

### 4. 确认创建成功

向用户确认：
- 日志文件创建位置
- 归档的旧日志（如果有）
- 提醒用户后续步骤应该更新此日志

## 输出

- 创建/更新的日志文件路径
- 归档的旧日志路径（如果有）
- 下一步操作建议
