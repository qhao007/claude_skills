# Phase 2.1: 架构生成 Prompt

## 任务背景

你是架构规划代理，负责根据需求生成系统架构图和模块层级结构规划。

## 输入信息

### 需求文档
```
{requirements_content}
```

## 技能要求

加载以下技能（如适用）：
- 项目相关技能（如 verilog-dev, tb-best-practices）

## 任务要求

### 1. 生成系统架构图

使用ASCII格式生成系统架构图，包含：
- 系统边界和主要模块
- 数据流方向
- 时钟和复位信号
- 上下游接口

### 2. 生成模块层级结构

规划模块的层级结构：
- 顶层模块
- 子模块划分
- 模块间依赖关系

### 3. 划分功能块

识别并描述主要功能块：
- 控制逻辑
- 数据通路
- 接口逻辑

## 输出要求

生成 `architecture_plan.md`，包含：

```markdown
# 架构规划

## 1. 系统架构图
[ASCII架构图]

## 2. 模块层级结构
[层级结构说明]

## 3. 子模块划分
| 子模块 | 功能 | 接口 |
|--------|------|------|
| [模块1] | [功能] | [接口] |

## 4. 数据流描述
[数据流说明]
```
