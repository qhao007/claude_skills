# 代码开发工作流

## 概述

代码开发工作流，通过4个阶段子代理完成完整开发流程：
- **Subagent A (开发)**：读取规格书，开发代码
- **Subagent B (审查)**：代码审查，决策是否需要优化（1-3轮）
- **Subagent C (测试)**：测试/debug/代码修复
- **Subagent D (确认)**：测试结果确认 + 修复

## 输入要求

- 规格文档路径 (spec.md)
- 参考文档 (可选)
- 项目基础信息 (自动从CLAUDE.md加载)

## 阶段配置总览

| 阶段 | 子代理 | 模型 | max_retries | 推理深度 |
|------|--------|------|-------------|---------|
| 开发 | A | sonnet | 3 | 高 |
| 审查 | B | opus | 3 | 极高 |
| 优化 | A | sonnet | 3 | 高 |
| 测试 | C | sonnet | 3 | 中高 |
| 确认 | D | sonnet | 3 | 中 |

# 工作流执行流程

## 完整流程

```
1. 验证输入
   ├── 检查规格文档是否存在
   └── 加载项目基础信息 (CLAUDE.md)

2. 阶段1: 代码开发 (Subagent A)
   ├── max_retries: 3
   ├── 模型: sonnet
   └── 输出: 代码实现 + 自检报告

3. 阶段2: 代码审查 (Subagent B)
   ├── max_retries: 3
   ├── 模型: opus
   ├── 输出: 审查意见 + 优化决策
   └── 决策: 需要优化? 轮次1-3?

4. 循环优化 (1-3轮，由B决定)
   ├── 阶段3: 优化确认 (Subagent A)
   │   ├── max_retries: 3
   │   └── 输出: 优化后代码
   └── 循环直到达到决策的轮次数

5. 阶段4: 测试/Debug (Subagent C)
   ├── max_retries: 3
   ├── 模型: sonnet
   └── 输出: 测试结果 + 修复内容

6. 阶段5: 结果确认 + 修复 (Subagent D)
   ├── max_retries: 3
   ├── 模型: sonnet
   ├── 输出: 审核报告 + 修复详情 + 最终结论
   └── 结论: 可合并 / 需人工审核

7. 输出最终报告 → 人工审核
```

## 循环控制逻辑

```python
# 伪代码
loop_count = 0
max_loops = 3
min_loops = 1

# B审查后决定
optimization_loops_needed = B.decide_optimization_loops()
optimization_loops_needed = max(min_loops, min(max_loops, optimization_loops_needed))

while loop_count < optimization_loops_needed:
    loop_count += 1
    # 执行优化
    result = execute_stage("optimize", agent=A)
    # 如果不是最后一轮，再次审查
    if loop_count < optimization_loops_needed:
        result = execute_stage("review", agent=B)
```

## 错误处理流程

```python
# 每个阶段的通用错误处理
def execute_stage_with_retry(stage_name, agent, inputs, max_retries=3):
    attempts = 0

    while attempts < max_retries:
        try:
            result = agent.execute(inputs)
            if result.is_valid():
                return result
            else:
                attempts += 1
                # 记录错误，继续重试
        except Exception as e:
            attempts += 1
            # 分析错误原因，尝试修复后重试

    # 所有重试都失败
    return ErrorResult(error=f"阶段 {stage_name} 执行失败，已重试{max_retries}次")
```

# 调用示例

## 启动工作流

```
用户输入:
/workflow run code_development --spec docs/spec.md

工作流执行:
1. 检查 docs/spec.md 是否存在
2. 加载项目基础信息
```

## 阶段间传递的信息

每个阶段传递给下一阶段的内容：
- 阶段1 → 阶段2: 代码实现 + 自检报告
- 阶段2 → 阶段3: 审查意见 + 优化轮次
- 阶段3 → 阶段2: 优化后代码（如果需要多轮）
- 阶段3 → 阶段4: 优化后代码
- 阶段4 → 阶段5: 测试结果 + 修复内容
- 阶段5 → 最终: 审核报告 + 修复详情 + 结论
